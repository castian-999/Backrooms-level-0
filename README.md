# 📚🟨 BACKROOMS: LEVEL 0 – STUDY RPG

Backrooms: Level 0 – Study RPG is a long-term study marathon structured as a psychological RPG inspired by Level 0 of the Backrooms.

There are no visible monsters in this game.
The real enemies are disorientation, mental fatigue, repetition, and quitting.

The goal is not to rush forward, but to survive Level 0 through a strict, repetitive, and progressive study method until an exit is found.

🟨 LEVEL 0 (Narrative)

Level 0 represents the beginning.

A space that is:

- non-linear  
- silent  
- repetitive  
- psychologically exhausting  

Just like studying, you move forward without clear signs of progress, return to familiar places, experience déjà vu, and question your direction.

There are no entities.
If something appears as a distraction, a voice, an easy shortcut, or false companionship, it is not human.

🧠 Study Method (Game Mechanics)

Each chapter is treated as a room in Level 0.

To clear a room, ALL steps below must be completed:

Read the entire chapter

Solve all examples

Solve exercises:

Up to a maximum of 25 exercises per chapter

Correct all exercises

Write, in your own words:

What you understood from the chapter

Create active reviews:

Flashcards

5 review questions

🔁 Review System (Psychological Loop)

Each completed chapter must be reviewed at:

1 day after study

7 days after study

30 days after study

Each review consists of:

Reviewing flashcards

Solving 5 questions

Skipping a review is equivalent to getting lost in Level 0.

⚠️ Level 0 Rules

No skipping chapters

No skipping examples

No accumulating corrections

No “vibe-based studying”

No advancing without completing the full cycle

False progress is a common hallucination in this level.

🚪 Exiting Level 0

Exit is only possible when:

All listed books are completed

All reviews (1, 7, and 30 days) are done

Progress is clearly documented

After completing Level 0, the player may advance to Level 1, where content density and interdisciplinary integration increase.

📌 Final Warning

This is not a quick challenge.
This is not motivational fluff.

This is a mental endurance test.

If you hear footsteps, voices, or promises of shortcuts, ignore them.
Keep walking.
